# Liquid Glass Campus Workspace

## Palette

- Deep blue-black base: `#08111F`
- Frosted glass: `rgba(255, 255, 255, 0.08)`
- Text: `#F4F7FB`
- Muted text: `#AAB7C8`
- Signature: `#76A7FF`
- Secondary accent: `#A78BFA`
- Success: `#68D391`
- Warning: `#F6C76A`
- Destructive: `#FF7A7A`

## Type

Use the platform system sans for all interface text. Keep a strong 1.25 type scale, with short headings and readable 14-16px body copy.

## Surface System

Liquid glass surfaces use a translucent fill, a 1px white highlight border, soft inward and outward depth, and restrained backdrop blur. The shell is dark; glass appears only on containers that need separation. Avoid glossy gradients on every element.

## Layout

Desktop: fixed 272px navigation rail with a roomy content canvas.
Mobile: a compact glass header with an overlay navigation sheet.
Page content: 24-32px gutters, dense tables and rows, and short work queues.

## Motion

Use quick 150-220ms transitions for hover and state changes. Dialogs and sheets may use one subtle scale/fade reveal. No staggered page entrance or continuously pulsing effects.
